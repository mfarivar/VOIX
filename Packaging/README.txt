VOIX — push-to-talk dictation for macOS
https://github.com/mfarivar/VOIX

INSTALL
1. Drag VOIX into Applications, then open it from Applications.
2. Allow Microphone and Speech Recognition when asked, and turn VOIX on under
   System Settings → Privacy & Security → Accessibility.

USE
Hold Right ⌥ Option, speak, release — the text is pasted where you're typing.
Press Esc while holding to cancel. Everything else is in the menu bar icon.

OPTIONAL: WHISPER
Right-click "Install Whisper.command" → Open. It installs whisper.cpp with
Homebrew and downloads the English models (~640 MB). Then choose a model
under VOIX → Speech Engine.
