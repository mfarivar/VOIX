VOIX — push-to-talk dictation

1. Drag VOIX into Applications, then open it from Applications.
   If macOS says it can't verify the developer: System Settings → Privacy & Security
   → scroll down → "Open Anyway" (needed once per Mac).
2. Allow Microphone and Speech Recognition, and turn VOIX on under
   System Settings → Privacy & Security → Accessibility.
3. Hold Right ⌥ Option, speak, release. Everything else is in the menu bar icon.

Optional: double-click "Install Whisper.command" to add the Whisper engines
(needs Homebrew, downloads ~640 MB).
